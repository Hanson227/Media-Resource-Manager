## 关键坑：本机 agent 执行环境的 ELECTRON_RUN_AS_NODE

- agent 的 PowerShell/Bash 会话里带 `ELECTRON_RUN_AS_NODE=1`，直接启动任何 Electron 应用会被当成 node 跑：
  - 无参数 → 0.5s 内 exit code 0，无窗口；
  - 带 `--user-data-dir=...` → 报 `bad option`，exit code 9。
- 即使清掉该变量，从 agent 沙箱里启动的 Electron 仍会出现 GPU/renderer 子进程 `0xC0000005` 反复崩溃
  （`FATAL: GPU process isn't usable. Goodbye.`），加 `--no-sandbox --disable-gpu-sandbox` 才能跑起来 ——
  这是**沙箱环境造成的假象**，不是应用 bug。判断真实行为必须用 `explorer.exe` 拉起，脱离 agent 进程树。
