# Web UI 增强设计

## 改动范围

全部在 `desktop/web/index.html` 内，不涉及后端。

---

## 1. 单元首页：双列大图网格 + 排序

### 当前问题
单元卡片封面缩略图只有 60×45px，太小，无法通过缩略图区分文件夹。没有排序功能。

### 设计

```
┌─────────────────┬─────────────────┐
│     16:9 封面    │     16:9 封面    │
│                 │                 │
├─────────────────├─────────────────┤
│ 📂 网友自拍      │ 📂 旅行合集      │
│ 14 文件 · 753 MB │ 23 文件 · 1.2 GB│
└─────────────────┴─────────────────┘
    ↕ 按文件名        ↕ 按大小
```

- 2 列网格，`gap: 10px`，卡片 `border-radius: 12px`，背景 `#1c1c1e`
- 封面 16:9 缩略图 `object-fit: cover`，加载失败显示文件夹图标
- 下方显示：文件夹名（14px 粗体）、文件数 + 总大小（12px #8e8e93）
- **顶部栏加排序按钮**：点击切换排序方式（文件名/大小），再次点击切换升/降序
- 单元按根目录折叠分组的逻辑不变，排序在每个组内生效

### 涉及修改
- `UnitsPage`：模板改为 2 列 `grid`，移除 `card-row` / `card-icon`，改为大封面布局
- `UnitsPage`：新增 `sortBy` / `sortOrder` data + 排序方法
- `UnitsPage`：顶部 `root-header` 内加排序按钮
- CSS：新增双列网格卡片样式，移除旧的 `.card-cover` 小缩略图样式

## 2. 文件页：顶部排序

### 当前问题
文件页按 ID 排序显示，无法按文件名或大小排列。

### 设计

- 在顶部标题栏右侧添加排序按钮，和"共 N 个文件"同行
- 点击弹出排序菜单：按名称 / 按大小
- 选中后数据重新排序渲染，菜单关闭
- 当前排序方式文字显示在按钮上（如 "↓ 名称"）
- 再次点击切换升降序

### 涉及修改
- `UnitFilesPage`：新增 `sortBy` / `sortOrder` data + `sortedFiles` 计算属性
- `UnitFilesPage`：模板 title 旁加排序按钮
- `UnitFilesPage`：点击文件预览前保存滚动位置（见第 3 项）

---

## 3. 预览返回滚动位置

### 当前问题
从文件页点进视频/图片预览，返回时页面重新加载到最顶端，用户需要重新滚动到之前浏览的位置。

### 设计

- `UnitFilesPage` 新增 data `_savedScrollTop: 0`
- `preview(file)` 方法在 `$router.push` 前保存 `该页面 app-main 的 scrollTop`
- `mounted()` 中检查 `_savedScrollTop > 0`，有则在 `$nextTick` 后用 `scrollTo(0, _savedScrollTop)` 恢复
- 恢复后清零 `_savedScrollTop`，避免重复滚动

### 涉及修改
- `UnitFilesPage`：新增 data + 保存/恢复逻辑
